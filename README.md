## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Aravind628187/Aravind-portfolio.git
```

Move into project folder:

```bash
cd Aravind-portfolio
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Open browser:

```bash
http://localhost:5173
```

---

## 📦 Build For Production

```bash
npm run build
```

Preview build:

```bash
npm run preview
```
